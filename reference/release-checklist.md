# 雛形の公開前チェックリスト（配布する人用）

Notion の雛形（DB の枠組み）を他の人に配るときに、**自分の個人情報が一緒に配られない**ようにするための一覧です。
スクリプト（`check_privacy.py`）は GitHub に上げるファイルしか見られません。**Notion 側は人の目で確認します。**

> 雛形を「自分が普段使っている DB の複製」から作ると、列の選択肢・ビューの条件・版履歴などに、作品名やイベント名が残りやすくなります。
> **新しく作る**のが最も安全です。

---

## 0. 作る場所と作り方

- □ **個人情報が入っていない、空の専用ページ**の下に作る（できれば、普段使っているのとは**別のワークスペース**。同じワークスペースで作ると、メンバー名・検索結果・リンク先に自分の情報が混ざりやすい）
- □ **既存の DB を複製せず**、一から作った（列の仕様は `config/columns.json`・`manual/02-notion-setup.md`）
- □ 配る DB の中身（行）は**空**。試用のダミーデータは、別の DB／別のページに分ける
- □ 公開用では、DB の名前を `config/schema.json` の `db_names`（日次ログ／イベント／Tasks）に**合わせる**
  - 準備中の下書きに「（雛形）」などの印を付けている場合は、公開用で外す（外さないと、複製した人の AI が DB を見つけられない）
  - 逆に、**自分のワークスペースに同じ名前の DB が別にある間は**、公開用の名前にしない（自分の AI が取り違えて止まります）

---

## 1. 中身に個人情報が残っていないか

雛形のページと 3 つの DB について、**1 つずつ開いて**確認します。

| 場所 | 見るもの | 確認 |
|---|---|---|
| ページ・DB の**名前** | 自分の名前、作品名、サークル名 | □ |
| DB の**説明文** | 同上 | □ |
| **列の名前・列の説明文** | 作品名やイベント名が列名になっていないか | □ |
| **選択肢の名前**（進捗・種別・状態・区分・工程・カテゴリ・優先度など） | 実在の作品名・イベント名・人名が選択肢に残っていないか。**使っていない選択肢**も見る | □ |
| **既定値**・DB の**テンプレート**（新規行のひな形）の中身 | 文章・日付・メンション | □ |
| **ビュー**（表・カレンダー・ボードなど）の**フィルター・並び替え・グループ名** | フィルターの値に作品名などが入っていないか | □ |
| **ページ本文**（DB の外のページの文章） | 説明文にサークル名・SNS の ID・メールアドレス・URL が入っていないか | □ |
| **アイコン・カバー画像** | 自分のイラスト・写真・ロゴ | □ |
| **コメント・メンション** | 自分や他の人の名前、コメントの履歴 | □ |
| **リレーの接続先** | 雛形の外の DB（自分の実データの DB）につながっていないか。3 つの DB の間だけでつながっている | □ |
| **版履歴**（ページの履歴） | 複製や貼り付けで作ったとき、元の内容が履歴に残る。新規作成なら問題なし | □ |
| **作成者・最終編集者の表示** | 自分の名前・アイコンが表示される範囲か（別ワークスペースなら表示されにくい） | □ |
| **親ページの階層**（ページの上のパンくず） | 親ページの名前に個人情報がないか | □ |
| **ファイル・埋め込み・外部リンク** | 自分の資料・自分のサイトへのリンクが残っていないか | □ |

---

## 2. 共有設定

- □ 共有する対象は**雛形のページ 1 つだけ**。親ページ（ワークスペース全体、自分の資料のページ）は共有されていない
- □ メンバー・ゲストの招待が、意図したものだけ
- □ 「ウェブ公開」にする場合: **検索エンジンへの掲載はオフ**、**複製を許可**（利用者が自分の Notion にコピーできる）、**編集は不可**
- □ 公開しない（限定共有）場合は、リンクを知っている人が誰でも見られる設定になっていない
- □ 接続（インテグレーション）の一覧に、雛形のページが接続されていない（自分の AI が雛形を読んでしまわないように）

---

## 3. 公開した直後（ここまでやって、はじめて完了）

- □ **ログアウトした状態**（または別のアカウント）でリンクを開き、見えるものが想定どおりか確かめた
- □ そのアカウントで**複製**してみて、複製された先の DB 名・列・選択肢が想定どおりで、行が空であることを確かめた
- □ 複製された先で、AI を接続し、**1 回更新を通して**みた（`manual/04-ai-prompts.md` の「試運転」→「更新して見せる」）。最初の更新で、列名のずれの警告が出ないこと
- □ 公開リンクを README などに書くときは、**雛形のリンクだけ**（自分の実データのページのリンクを書かない）

---

## 4. 公開後の運用

- □ 雛形の列や選択肢を変えたら、`config/columns.json`・`manual/02-notion-setup.md`・`CHANGELOG.md` を同時に直す（片方だけ変えると、利用者の画面が黙って空になる、または更新が止まる）
- □ **すでに使っている人の DB は、雛形を直しても変わらない。** 列名を変えるような変更は避け、やむを得ない場合は、`CHANGELOG.md` に移行手順を書く
- □ 定期的（月 1 回など）に、**別アカウントで複製して通す**確認をする

---

## このチェックリストの限界
- 人が見落とすことがあります。**2 人で（または時間を置いて 2 回）**確認すると確実です。
- Notion の仕様変更で、表示される場所が変わることがあります。
- 自動で確かめられるのは、GitHub に上げるファイルの形式の検査だけです（`python3 scripts/check_privacy.py`）。
