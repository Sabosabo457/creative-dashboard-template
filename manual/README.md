# マニュアルの読む順

利用者が読むものは、このフォルダに集めています。**番号の順に、必要なところまで**読んでください。
設計の資料や、雛形を配る人向けの資料は `reference/` にあります（通常は読まなくて構いません）。

| 順 | 文書 | 内容 |
|---|---|---|
| 1 | `01-manual.md` | 全体像、試運転、初回の手順、画面の見方、ファイルの説明、困ったとき |
| 2 | `02-notion-setup.md` | Notion のアカウント登録、データベースの作り方、列の表 |
| 3 | `03-connectors.md` | AI と Notion をつなぎ、読み取りだけに絞る |
| 4 | `04-ai-prompts.md` | Claude に頼むときの依頼文 |
| 5 | `05-checklist.md` | 初回・更新のたび・月 1 回の確認項目 |

## 必要になったら
| 文書 | こんなとき |
|---|---|
| `06-customize.md` | 列の名前や選択肢を自分向けに変えたい |
| `07-privacy.md` | 個人情報がどう守られるか知りたい |
| `08-claude-live.md` | 画面を開くたびに最新にしたい（Claude 専用） |
| `10-chatgpt-guide.md` | **ChatGPT と Notion だけで作りたい**（接続から画面を開くまでの手順、まとめファイル、Notion の雛形） |
| `09-chatgpt.md` | ChatGPT での試験の手順と結果（実験的） |

変更履歴と更新の取り込み方は、一番上の `CHANGELOG.md` にあります。
