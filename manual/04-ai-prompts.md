# AI への頼み方（標準は Claude）

運用の中身は `AGENTS.md` に書いてあります。**主な対象は ChatGPT を使う人**で、通しの確認は ChatGPT と Claude で行いました。Gemini は、同じ文で動く可能性はありますが未確認です（参考扱い）。

## 使い方は 2 つ

| 動線 | 内容 | 必要なもの |
|---|---|---|
| **W. AI で完結（メイン・Web）** | AI が Notion を読み、画面を作って渡す。**ターミナルも `.env` も不要** | Notion に接続でき、ファイルを作ってコードを実行できる AI |
| **P. PC のスクリプト（任意）** | 自分のパソコンで 3 つのコマンドを実行。AI を使わずに済む。実データを AI に渡さない | Python、Notion のトークン（`.env`） |

## 動線 W の準備（初回だけ）
1. AI に Notion を接続する（その AI の「コネクタ」「アプリ連携」などの設定から）。可能なら、権限は**読み取りのみ**にし、「日次ログ」「イベント」「Tasks」だけを共有する。
2. このテンプレート一式（または `AGENTS.md` と `scripts/`・`template/`・`config/`・`manual/`・`reference/`）を AI の作業環境に置く。
   - **Claude（標準）**: プロジェクトにファイルを入れる／Claude Code でフォルダを開く。
   - ChatGPT・Gemini（参考・未確認）: 添付するか、コード実行のできる環境にフォルダを入れる。
3. 最初のメッセージで「AGENTS.md の絶対ルールを守ってください」と添える。

## コピペ用プロンプト（動線 W）

### 試運転（Notion なし）
```
AGENTS.md に従って、ダミーデータでダッシュボードを作って見せてください（build.py --sample）。
```

### ダッシュボードを更新して見せる（毎週）
```
AGENTS.md の動線 W に従って、Notion の日次ログ・イベント・Tasks を読み取り専用で読み、
ダッシュボードを更新して見せてください。画面は非公開のまま渡し、共有リンクは作らないでください。
最後に件数と最終更新日を教えてください。
```

### 本文も画面に出して更新する（任意・既定はオフ）
```
config/settings.local.json に {"include_text": true} と書いて、上と同じ更新をしてください。
画面に創作の中身が入るので、非公開のまま渡してください。
```
（何も言わなければ、内容・作品は読み込まず、画面にも出ません。）

### 件数を確かめる
```
更新後の件数（日次ログ N 件・記録のある日 M 日／イベント／Tasks）を教えてください。
「注意:」や「更新を止めました」が出た場合は、省略せずそのまま教えてください。
```
（Notion の表の下で「計算 → カウント」を選ぶと件数が出ます。一致するか見てください。）

### DB や列の名前が自分用に違うとき
```
私の DB 名は「（自分の名前）」です。config/schema.local.json に DB 名の対応を書いてください。
列名が違うときも、更新が止まった内容に従って schema.local.json に対応を書いてください。
```

### 今日の進捗を Notion に登録する
```
AGENTS.md の書き込みルールに従って、日次ログに今日の進捗を 1 行登録してください。
内容: （1 行）／ 種別: （プロット / ラフ / ペン入れ / 彩色 / 清書 / 設定整理 / ほか）
同名のページがあれば更新、なければ作成。進捗は「あり」。登録前に内容を確認させてください。
```
（Notion に自分で 1 行入れるだけでも構いません。30 秒です。）

### イベントを登録して準備の見出しを作る
```
イベント DB に次のイベントを登録し、manual/02-notion-setup.md の「イベント準備の目安」に従って
Tasks に準備の見出しと期限を作ってください。作る前に一覧を見せてください。
イベント名: ／ 開催日: ／ 申込締切日: ／ 区分:
```

### 今週のまとめ
```
Notion の日次ログから今週分を読み、「進捗あり」の日数、種別、来週の期限を事実だけで 3〜4 行にまとめてください。評価や叱責はしないでください。
```

## 動線 P のとき
```
python3 scripts/fetch_notion.py
python3 scripts/make_datasets.py
python3 scripts/build.py      # → out/index.html をブラウザで開く
```
AI に頼むのは、エラーが出たときだけで十分です。

```
次のエラーの原因と直し方を、初心者向けに 1 つずつ教えてください。
（エラー文。トークン・ID・作品名が含まれていないか確認してから貼る）
```

## やってはいけないこと
- `.env` の中身や、トークン・DB の ID をチャットに貼る。
- 動線 P で作った `data/real/` や `out/index.html` を、AI やほかの人に渡す。
- 画面のリンク共有を有効にする（動線 W で AI が公開ページを作れる場合）。
